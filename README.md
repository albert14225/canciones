# 🎵 Repositorio de Canciones Comunitario

¡Bienvenido al repositorio colaborativo de canciones!
Aquí puedes **subir tus canciones favoritas en formato `.mp3`**, organizadas y accesibles para que todos las puedan escuchar desde GitHub Pages o un reproductor en la web.

---

## 📁 Estructura del proyecto

Coloca tus canciones dentro de la carpeta `/canciones/`, siguiendo este formato:

```
/canciones/
├── autor-nombre/
│   ├── titulo-de-la-cancion.mp3
│   └── info.txt (opcional)
```

🔸 **Ejemplo:**

```
/canciones/
├── soda-stereo/
│   ├── de-musica-ligera.mp3
│   └── info.txt
```

---

## 📝 Reglas para contribuir

1. ✅ **Usa nombres de carpetas y archivos en minúsculas** y con guiones en lugar de espacios.
2. ✅ El archivo `.mp3` debe tener buena calidad y estar correctamente nombrado:
   `titulo-de-la-cancion.mp3`
3. 📝 Puedes agregar un archivo `info.txt` opcional con detalles como:

   * Autor
   * Año
   * Álbum
   * Letra (si aplica)
4. ❌ No subir canciones con derechos reservados **sin autorización**. Este repositorio está pensado para:

   * Música libre
   * Producción propia
   * Covers con permiso
   * Dominio público

---
